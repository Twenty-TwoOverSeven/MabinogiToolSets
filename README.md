# 洛奇战斗力计算器

这是一个零构建依赖的本地静态网页计算器，用于根据角色白值和 G13 及以前技能等级估算洛奇战斗力。

## 使用方式

直接用浏览器打开 `index.html`。

项目不依赖 npm、Node 包管理器、Vite 或任何构建步骤。所有脚本都是普通浏览器脚本，按顺序加载，目标是支持直接从本地文件打开。

## 数据保存

浏览器会用 `localStorage` 临时自动保存当前编辑状态，但这不适合作为长期存档。请使用页面顶部的“导出 JSON”备份全部角色档案。

导入支持两种模式：

- 替换导入：用 JSON 文件替换当前全部角色档案。
- 合并导入：保留当前档案，把 JSON 文件里的角色追加进来；同名角色会自动加后缀。

## 验证

直接用浏览器打开 `tests/browser-tests.html`，页面应显示全部测试通过。

手动验证清单：

- 打开 `index.html` 后显示“洛奇战斗力计算器”。
- 可以新建、切换、复制、删除角色，并且至少保留一个角色。
- 修改力量为 `100`，总战斗力显示 `100.00`。
- 搜索并添加防御，将等级改为 `1`，最高技能显示 `防御 400`。
- 技能列表中最高贡献技能行高亮，但不显示“最高”标签。
- 导出 JSON 后可以下载包含角色数据的文件。
- 使用替换导入可以恢复导出的角色数据。

## 数据说明

技能战斗力数据参考台湾版资料页 `https://mabinogi.fws.tw/skills_combat_power.php`。当前只录入已确认译名的 G13 前示例技能，完整 G13 技能表需要继续由用户提供或校对大陆简体译名后补充。
